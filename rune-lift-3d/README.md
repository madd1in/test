# Rune Lift 3D

A static Three.js puzzle platformer with Assist and Normal difficulty, double jump assists, optional helper ledges, guide wisps, visible safety nets, a target compass, route rails, a new Aurora/Crown finale, swipe touch controls, locally generated materials, calm BGM from `Downloads`, and short SFX. The renderer defaults to a performance-first mobile path with fewer point lights, lower texture cost, capped pixel ratio, and adaptive quality.

## Run locally

```powershell
cd rune-lift-3d
npm install
npm run serve
```

Open `http://localhost:4177`.

## Controls

- Keyboard: WASD or arrow keys to move, Space to jump or double jump in Assist, H to toggle Assist/Normal, R to reset, M to mute.
- Touch: drag to move, swipe up to jump or double jump, swipe down to reset.
