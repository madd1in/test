# Overcrest Rally 3D

Ein neues 3D-Rally-Time-Trial fuer den Browser: drei offene Stages, Chase-Camera, Drift/Handbrake-Physik, Pace Notes, Split-Gates, Schaden, Wettereffekte, Minimap und Touch-Steuerung.

## Start

```powershell
npm.cmd run serve
```

Dann `http://127.0.0.1:4193` oeffnen.

## Steuerung

- Gas: `W` oder `ArrowUp`
- Bremse/Rueckwaerts: `S` oder `ArrowDown`
- Lenken: `A` / `D` oder Pfeiltasten
- Handbremse: `Space` oder `Shift`
- Pause: `P` oder `Escape`
- Restart: `R`

Touch-Controls erscheinen auf kleinen Viewports.

## Checks

```powershell
npm.cmd run check
```
