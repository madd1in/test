# Turbo Rally - Coastal Circuit

Eigenstaendiger Browser-Racer in diesem Projektordner.

## Enthalten

- [x] Lokale `index.html`, `style.css` und `js/game.js`
- [x] Pseudo-3D-Rennstrecke mit Kurven, Huegeln, Boost-Pads, Rampen und Minimap
- [x] Drei originale Karts mit unterschiedlichen Fahreigenschaften
- [x] Gegner-KI, Platzierung, Rundenzaehler und Rennzeit
- [x] Drift-Boost, Slipstream, Jump-Tricks und Overdrive
- [x] Item-Boxen mit Turbo, Pulse, Oelspur, Shield und Magnet
- [x] Coins als Risiko-/Belohnungs-Linie fuer Overdrive-Aufladung
- [x] Style-Score, Combo-Kette und Canvas-Popups fuer saubere Fahraktionen
- [x] Storm-Lap ab Runde 2 mit Regen, Blitzen, nasser Strecke und Pfuetzen
- [x] Generierte BGM und SFX per Web Audio API
- [x] Tastatur- und Touch-Steuerung
- [x] Swipe-Steuerung auf dem Canvas und Vollbild-Schalter
- [x] Originale KI-generierte Sprite-, Tile- und Kartenassets
- [x] Keine extern geladenen Spielskripte im Startpfad
