# Foldscape

Small browser prototype with a textured 3D platform map, double jump, touch controls, fullscreen toggle, and imported BGM.

## Included assets

- `assets/foldscape_sprite_sheet.png` and `assets/foldscape_tilemap.png` are generated raster sheets from `tools/build-assets.ps1`.
- `assets/imported/imagegen-concept-sheet.png` is the Imagegen source/concept sheet generated for this pass.
- `assets/imported/observatory.png` and `assets/audio/moonlit-maple-trail.mp3` were copied from `C:\Users\User\Downloads` subfolders and are used in-game.

## Run

Open `index.html` directly, or serve this folder with any local static server.
