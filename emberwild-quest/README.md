# Emberwild Quest

A new top-down action adventure browser game built with Phaser and local PNG image assets.

## Play

```powershell
python -m http.server 4179
```

Then open `http://localhost:4179`.

## Controls

- Move: WASD or arrow keys
- Attack: Space or left mouse
- Dash: Shift
- Interact: E
- Pulse: Q reveals the nearest shard, cache, gate, or boss echo
- Pause: Esc

## Goal

Collect five ember shards, find the sunken key, open the north gate, and defeat the Ash Warden.

## Assets

HD illustration assets were generated with the built-in Image Gen tool and saved into:

- `assets/generated/emberwild-key-art.png`
- `assets/generated/emberwild-shrine-hd.png`
- `assets/generated/ashwarden-boss-hd.png`
- `assets/generated/tile-atlas-imagen-hd-source.png`

The active in-game terrain sheet is sliced from the Image Gen atlas with
`tools/prepare_imagen_tiles.py`:

- `assets/environment/tiles-imagen-hd.png`

Other in-game sprite sheets are project-local PNG assets generated by
`tools/generate_assets.py`:

- `assets/environment/tiles.png`
- `assets/environment/objects.png`
- `assets/characters/player.png`
- `assets/characters/thornling.png`
- `assets/characters/ashwarden.png`
- `assets/fx/slash.png`
- `assets/ui/icons.png`

Audio was copied from local disk into `assets/audio`:

- BGM: `moonlit-castle-ruins.mp3`, `ashwarden-boss.mp3`
- SFX: slash, dash, pickup, gate, beacon, enemy hurt, player hit, heal, confirm, boss defeat
