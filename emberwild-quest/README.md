# Emberwild Quest

A new top-down action adventure browser game built with Phaser and local PNG image assets.

## Play

```powershell
python -m http.server 4179
```

Then open `http://localhost:4179`.

## Controls

- Move: WASD or arrow keys
- Attack: Space or left mouse
- Dash: Shift
- Interact: E
- Pause: Esc

## Goal

Collect five ember shards, find the sunken key, open the north gate, and defeat the Ash Warden.

## Assets

The menu key art was generated with the built-in Image Gen tool and saved into
`assets/generated/emberwild-key-art.png`.

The in-game sprite sheets and tiles are project-local PNG assets generated by
`tools/generate_assets.py`:

- `assets/environment/tiles.png`
- `assets/environment/objects.png`
- `assets/characters/player.png`
- `assets/characters/thornling.png`
- `assets/characters/ashwarden.png`
- `assets/fx/slash.png`
- `assets/ui/icons.png`
