# Crypt Runner 3D

Standalone Three.js endless runner for GitHub Pages.

## Play

- Run forward through three lanes.
- Collect green shards and violet boost rings.
- Jump low gates and dash through trouble.

## Assets

HD art and MP3 files are copied from `C:\Users\User\Downloads` into `assets/`.

- `catacomb-hall.png`
- `castle-props.png`
- `gothic-atlas.png`
- `jet-fuel-glory.mp3`
- `steel-punch-parade.mp3`
- six short SFX clips

## Local

```bash
npm run check
npm run serve
```

Then open `http://127.0.0.1:4197/`.
